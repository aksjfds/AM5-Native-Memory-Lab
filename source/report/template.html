当前配置下的 Copy 短板分析

目标与边界

本报告只回答一个问题：在当前配置下，本程序的 Copy workload 最明显受哪条内存访问路径限制，以及对应哪些参数组值得优先检查。

它不会在没有反事实 A/B 的情况下声称某个具体时序一定能再压 1 cycle，也不会把“参数数值看起来大”当成短板。当前版本仍未读取 BIOS/UMC 实际参数；profile.ini 只作为临时参数快照展示，不参与评分。

Copy 短板排名

只对存在可识别证据的路径给 priority/watch。unresolved 表示测试看到了现象，但缺少 Bank/Row 映射、UMC 计数器或反事实设置，不能进入参数排名。

独立 Read / Write 对照

Copy 总逻辑 GB/s 按“读+写”计数，因此有效复制数据量为其一半。独立 Read/Write 不是并发 Copy 的严格物理上限，只用于判断哪一侧更接近自身能力边界。

Read/Write Turnaround Sweep

固定 50/50 总读写字节，仅改变 CPU 发出的连续读/连续写分组长度。若更少的方向切换持续稳定地降低单位字节耗时，才把 turnaround 参数组提高优先级。
